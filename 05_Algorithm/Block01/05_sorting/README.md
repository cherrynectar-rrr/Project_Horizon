# Sorting — 排序基础

[← 返回 Block 01](../README.md)

## 1. 本课概览

排序的意义不只是“把数字从小到大排好”。

更重要的是：

> **数据一旦有序，后面很多算法就可以利用这种结构。**

本课没有直接调用现成排序函数，而是从零实现最基础的选择排序（Selection Sort），用它理解：

- 一轮排序到底在做什么；
- 为什么每轮都要找剩余部分中的最小值；
- 为什么选择排序最好 / 最坏时间复杂度都是 `O(n^2)`；
- 为什么它可以原地完成，只用 `O(1)` 辅助空间。

---

## 2. 直觉 / Intuition

假设：

```text
[5, 2, 4, 1, 3]
```

如果想从小到大排序，一个非常自然的办法是：

1. 在整个数组里找到最小值 `1`；
2. 把它放到第一个位置；
3. 剩下的位置里再找最小值 `2`；
4. 放到第二个位置；
5. 重复这个过程。

也就是说，每一轮都在回答：

> **当前还没排好的部分里，谁最小？把它放到这一轮应该确定的位置。**

这就是选择排序最核心的直觉。

---

## 3. 核心思想 / Core Idea

假设 `start` 表示这一轮准备确定的位置。

那么每一轮：

1. 从 `[start, end)` 中寻找最小元素的下标；
2. 将这个最小元素和 `nums[start]` 交换；
3. `start` 向右移动一位。

可以把过程理解成：

```text
[已经确定] [还没确定]
```

每完成一轮，“已经确定”的区域就扩大一个位置。

当前代码把“找最小值下标”单独写成：

```cpp
findMinIndex(...)
```

然后排序函数负责重复调用并交换。

这种拆分也让算法结构更加清楚。

## 4. 手推 / Hand Simulation

原数组：

```text
[5, 2, 4, 1, 3]
```

### 第 1 轮

未排序区域：

```text
[5, 2, 4, 1, 3]
```

最小值是 `1`，与开头的 `5` 交换：

```text
[1, 2, 4, 5, 3]
```

现在第一个位置已经确定。

### 第 2 轮

只看：

```text
[2, 4, 5, 3]
```

最小值本来就是 `2`。

数组保持：

```text
[1, 2, 4, 5, 3]
```

### 第 3 轮

剩余：

```text
[4, 5, 3]
```

最小值是 `3`，交换后：

```text
[1, 2, 3, 5, 4]
```

### 第 4 轮

剩余：

```text
[5, 4]
```

交换：

```text
[1, 2, 3, 4, 5]
```

排序完成。

## 5. 实现 / Implementation

本课真实代码：[`main.cpp`](./main.cpp)。

### 找最小值下标

```cpp
std::size_t findMinIndex(const std::vector<int>& nums, std::size_t start)
{
    std::size_t index = start;
    for (std::size_t i = start + 1; i < nums.size(); i++)
    {
        if (nums[i] < nums[index])
        {
            index = i;
        }
    }
    return index;
}
```

### 每轮选择并交换

```cpp
void selectionSort(std::vector<int>& nums)
{
    std::size_t start;
    std::size_t minIndex;

    for (start = 0; start + 1 < nums.size(); start++)
    {
        minIndex = findMinIndex(nums, start);
        std::swap(nums[start], nums[minIndex]);
    }
}
```

这里的关键不是背函数名，而是明确两个职责：

```text
findMinIndex → 在剩余区域中找到最小值位置
selectionSort → 把它放到当前应该确定的位置
```

## 6. 复杂度 / Complexity

第一轮大约比较 `n - 1` 次。

第二轮大约比较 `n - 2` 次。

接着：

```text
(n - 1) + (n - 2) + ... + 1
```

数量级约为：

```text
n^2 / 2
```

忽略常数后：

```text
O(n^2)
```

即使数组一开始已经排好，当前选择排序仍然会逐轮寻找剩余部分中的最小值，所以：

| 情况 | 时间复杂度 |
| --- | --- |
| 最好 | `O(n^2)` |
| 最坏 | `O(n^2)` |

交换直接发生在原数组中，只使用固定数量变量，因此辅助空间：

```text
O(1)
```

## 7. 常见错误 / Common Mistakes

### 找到的是最小值，却忘了保存它的“下标”

最终要执行交换，需要知道位置，而不只是知道数值。

### 每轮都从数组第 0 位重新找

前面的区域已经确定，不应该重复参与后续最小值搜索。

### 以为数组已经有序时选择排序就是 `O(n)`

当前算法仍然需要完成所有比较，才能确认每轮剩余部分的最小值。

### 忘记最后一个位置不需要单独再找

当前 `n-1` 个位置已经确定，最后一个元素自然也确定，因此外层循环只需要到倒数第二个位置。
