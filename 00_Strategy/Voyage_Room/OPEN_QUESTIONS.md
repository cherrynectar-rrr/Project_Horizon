# Voyage Room — Open Questions

Last Updated: 2026-08-20

Open questions are strategic uncertainties, not automatically approved tasks. Project Control decides whether research or experiments receive resources.

## Active Questions

1. Which embodied-AI or robotics subdirection best matches demonstrated strengths after more real projects: perception, robot software, embedded/control, deployment/acceleration or systems integration?
2. What evidence package would most improve international graduate-study and career optionality over the next two to three years?
3. Which competitions, research experiences and internships provide genuine capability and evidence without fragmenting the active main line?
4. What financial, language and academic constraints must be understood before narrowing international education options?
5. What sustainable workload preserves health, curiosity and relationships while still producing meaningful technical progress?
6. What is the minimum readiness gate for the first technical internship, and should the first serious application window be the long winter break or summer 2027?

### First Technical Internship — Evidence Question

- Why it matters: The first internship can convert classroom/project ability into real engineering evidence and test whether C++/embedded/Linux/robotics-adjacent work actually fits the user.
- Decision horizon: Sophomore winter break through summer 2027.
- Verified facts: Career is not currently an activated specialist thread; current execution remains Python main line, Algorithm active, Linux support and C++ supporting algorithm work. Relevant 2026 internship postings commonly require sustained availability and practical programming/system skills rather than interest alone.
- Assumptions: A technically real but non-prestigious first internship may create more strategic value than waiting only for a famous robotics/AI company.
- Missing evidence: Exact winter-break dates; project portfolio quality by application time; C++/Linux readiness; geographic flexibility; whether suitable employers can accept a shorter winter internship.
- Reversible experiment: Build a small internship-readiness package and test a limited number of applications before committing substantial execution time.
- Owner for final decision: Project Control.
- Review trigger: When the user has at least one presentable engineering project plus enough C++/Linux fluency to interview, or when a concrete winter/summer internship opportunity appears.
