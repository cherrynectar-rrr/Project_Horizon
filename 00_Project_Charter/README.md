# Project Horizon Charter

This directory contains the constitutional and thread-startup documents of Project Horizon.

The Charter is the highest stable governance document. It defines the mission, durable principles, authority boundaries and decision model. It is intentionally separated from current priorities, weekly tasks, technical milestones and strategic hypotheses so the project can evolve without rewriting its constitution every time reality changes.

## Governance Hierarchy

1. **Charter** — mission, durable principles and authority boundaries.
2. **Operational protocol** — `../00_Project_Control/THREAD_PROTOCOL.md`.
3. **Horizon Core state** — `../00_Project_Control/MASTER_STATUS.md`.
4. **Strategic analyses** — preserved and current material under `../00_Strategy/Voyage_Room/` and other Core-owned strategy documents.
5. **Specialist execution state** — each domain's `STATUS.md`.
6. **Evidence** — code, projects, experiments, competition results, research outputs and other verifiable artifacts.

Chat memory is supporting context only. When chat memory conflicts with formal GitHub state, GitHub governs.

## Current Two-Layer Operating Model

### Horizon Core / 核心舱

**Explore + Decide & Coordinate**

Horizon Core is the single top-level role. For major decisions it preserves an internal two-pass discipline:

1. Explore alternatives, uncertainty, counter-cases and evidence gaps.
2. Decide or defer, allocate resources, state opportunity cost and define review triggers.

The existing Main Control chat evolved into Horizon Core on 2026-08-29. The former Voyage Room chat is historical / retired; its strategic function survives as Core Explore mode.

### Specialist Threads

**Execute**

Specialists perform bounded learning/projects, maintain factual evidence and their own state, and escalate strategic/cross-thread conflicts to Horizon Core.

## When the Charter Should Change

The Charter should change rarely. Appropriate triggers include:

- a genuine change to mission or durable values;
- repeated governance failure showing an authority rule is missing or ambiguous;
- a material change to the operating model;
- long-term evidence showing a supposedly stable principle should be revised.

Current priorities, specific competitions, countries being researched, software versions, individual course choices and weekly plans belong in lower-level documents.

## Core Principle

> The world is vast. I want to earn, through my own effort, the freedom to explore it, to keep creating, to understand more deeply, and to live the life I truly choose.
