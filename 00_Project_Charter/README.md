# Project Horizon Charter

This directory contains the guiding documents of Project Horizon.

The Charter defines the project's mission, vision, core principles, long-term roadmap, and decision rules. It exists to ensure that every learning path, technical project, internship choice, graduate application, and career decision remains aligned with the same long-term goal.

## Purpose

Project Horizon is not only a programming repository.

It is a long-term personal engineering project designed to build:

- strong engineering ability
- international competitiveness
- meaningful project experience
- long-term career freedom
- financial independence
- the ability to choose where and how to live

## Core Principle

> The world is vast. I want to earn, through my own effort, the freedom to explore it, to keep creating, and to live the life I truly choose.

## Current Version

## Usage

The Charter should be reviewed when:

- starting a new learning path
- choosing between different technical directions
- planning internships or graduate study
- making major career decisions
- updating long-term goals
- evaluating whether current work still serves the overall mission

## Versioning

Future updates should follow semantic-style document versions:

- `v1.0` — initial version
- `v1.1` — minor adjustments
- `v2.0` — major strategic revision

The Charter is intended to evolve together with Project Horizon.
