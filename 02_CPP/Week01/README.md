# C++ Week01

## Goal

Learn the basic C++ compile-run workflow and practice basic input/output and conditional statements.

## Current Features

- Compile C++ source code with `g++`
- Run the generated executable on Windows
- Read a device ID using `std::cin`
- Output values using `std::cout`
- Validate whether a device ID is greater than zero

## Build

```powershell
g++ main.cpp -Wall -Wextra -std=c++17 -o week01
```

## Run

```powershell
.\week01.exe
```

## Example

```text
Project Horizon C++ Week01
Enter device ID: 12
Device ID: 12
Valid device ID
```
